# Prototipo de recepción de mercadería

## Autor
- Nombre: Anderson Cruz
- Curso: Fundamentos de programacion.
- Docente: Danny .M

## Contexto
Proyecto académico basado en la observación del proceso de
recepción de mercadería en un restaurante KFC.

 Es un sistema oficial de la empresa.

## Problema identificado
El registro manual en un cuaderno depende de que el responsable
copie y revise los datos con exactitud.

Esto puede generar errores de transcripción, demoras en las
consultas y diferencias con el sistema digital.

Además, si el cuaderno se extravía, se moja o se deteriora,
puede perderse el único registro de las entregas y de las
diferencias reportadas al proveedor.

## Objetivo
Desarrollar un prototipo en Python para registrar, consultar
y conservar la información de recepción de mercadería.

## Caso de referencia
En la observación se identificó una recepción de pollo fresco
troceado, presentado en cajas de 20 kg.

Se solicitaron 40 cajas y se recibieron 38, por lo que se
registraron 2 cajas faltantes.

## Alternativa seleccionada
Se desarrollará un programa propio para adaptar el registro
y las consultas a las necesidades del proceso observado.

## Funcionalidades previstas
- Registrar entregas.
- Validar los datos ingresados.
- Calcular faltantes y excedentes.
- Consultar todas las entregas.
- Buscar por guía, proveedor o producto.
- Mostrar un resumen de diferencias.
- Guardar y recuperar registros mediante un archivo JSON.

## Organización prevista
- main.py: menú e integración.
- funciones.py: validaciones, registro y consultas.
- almacenamiento.py: lectura y guardado de datos.
